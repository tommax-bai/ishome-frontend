# admin-web（管理后台）

基座：**RuoYi-Vue-Plus**（RBAC、审计日志、字典、代码生成开箱；技术架构 §4.2）。

- 运营 CRUD（小区库、交付日历、选品池、三维资产 catalog、模板库配置）**全走基座代码生成**，不手写。
- **自研只砸一处：模板验收台**——模板上线前的一次性验收界面（设计时动作）：
  - 样张网格对比
  - 打分器分数透出
  - 验收 / 打回
  - 模板配置发布
- 运行时逐张实例全走机检门禁（consistency-check / compliance-check / scorer），质量信号由产品内嵌采集落 PostHog/ClickHouse。
