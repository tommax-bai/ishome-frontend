# c-app（C 端）

选型已定（技术架构 §4.1）：**uni-app（Vue3）一码双端**。

产品口径：

- **IM 会话为项目主线程**（channel-svc 可插拔渠道，首发飞书）：信息收集、确认、图片交付、召回都发生在聊天里。
- **H5 承接"指图时刻"**：看图点错确认、交付图对比标注、材质/风格视觉网格选择、3D 查看、支付等"指着图说话"的富交互。
- **小程序 = 分享卡片 + 支付容器**（微信系渠道接入后启用）。
- 每次 H5 交互结果回写一条摘要消息到聊天线程——聊天线程是用户可见的完整项目时间线。
- 不做 SSR，H5 落地页静态化。
